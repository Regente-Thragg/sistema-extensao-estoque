# 📦 GestãoFácil - Despensa em Casa

O **GestãoFácil** é um sistema web responsivo desenvolvido para o controle inteligente de estoque e gastos domésticos. O projeto centraliza a navegação, automatiza a manutenção de dados e oferece uma experiência de usuário (UI/UX) moderna com modais e alertas totalmente personalizados.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** React.js, Tailwind CSS, Vite
- **Back-end:** Node.js, Express.js, PostgreSQL (Supabase)
- **Gerenciamento de Estado:** React Hooks & Centralização Global no App.jsx

---

## 🌟 Principais Funcionalidades

- **Dashboard:** Acompanhamento financeiro em tempo real e log de atividades recentes.
- **Controle de Estoque:** Cadastro, reposição dinâmica de itens e consumo com baixas em tempo real.
- **Histórico Geral & Notificações:** Registro automático de compras e consumos com contador dinâmico.
- **Limpeza Automática e Manual:** Suporte a limpeza trimestral (90 dias) via banco de dados e botão de limpeza manual com preservação/reset configurável do total gasto no mês.
- **Interface Personalizada:** Modais próprios desenvolvidos em Tailwind CSS para exclusões, alertas e confirmações (sem caixas nativas do navegador).
